一起改进 Memory for Human

最有帮助的反馈是具体的一步：哪个问题不好回答，在哪里找不到按钮，恢复备份后有什么不对，哪种故事的提纲不合适。说明你想写什么、做到了哪一步，以及希望怎么改。

开发前阅读 AGENTS.md、三语 README 和相应 AI-HANDOFF。保持中文、英文、西班牙语的界面与帮助一致。核心或服务改动运行 npm test，操作流程变化再做真实浏览器检查。API 测试使用模拟服务；没有授权与真实凭据，不调用使用者的服务。

请用虚构或已授权并匿名化的示例。真实聊天、家庭照片、录音、地址、账号和 Key 不提交到公共仓库。

新功能先对照开发计划。还没实现的能力保留在计划中，引用第三方项目注明出处，独立工具不能写成已集成。技术比较说明资料范围，不把他人文档的遗漏当成功能缺失。

贡献需能按本项目的 PolyForm Noncommercial 1.0.0 分发，并保留必要的第三方声明。
