贡献说明

当前优先完善本地工具、三语说明、模板与采访体验。欢迎提出某个问题难回答、某类关系的章节不合适、材料入口不清楚或制作步骤遗漏等具体反馈。功能改动请按 AGENTS.md 运行有关测试与浏览器检查。

提交时说明：你尝试写哪种回忆录、卡在哪一步、希望怎样调整。请使用虚构或经过授权与匿名化的材料，不提交真实聊天、录音、家庭照片、地址、账号或密钥。

功能建议请先对应 docs/roadmap.md 中的阶段；未实现的功能不能在 README 中标为已支持。引用第三方资料写明出处，不将独立工具介绍写成已经完成的集成。

本项目采用 PolyForm Noncommercial 1.0.0。提交贡献前请阅读 LICENSE；拟纳入仓库的贡献需能够在本项目许可下分发，并保留必要的第三方说明。
