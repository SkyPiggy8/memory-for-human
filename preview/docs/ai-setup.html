让自己的 AI 带你开始

当前 v0.2 已有本地应用。入口是 start.cmd（Windows），或 Node.js 22+ 下的 sh start.sh / node server.mjs。Windows 启动器可以准备并校验官方 LTS 运行环境；默认不需要管理员安装。

把以下话与仓库交给自己的 AI：

请帮助我使用 Memory for Human。我不懂编程。
请先读 README 和适合我语言的 AI-HANDOFF 文档。
能操作本机时，按实际启动文件帮我打开本地应用；不能操作时，
用简单语言一步步教我，不声称已经替我安装。
先带我选一种回忆录，再讲一段回忆。没有 API Key 就用手动交接方式。
我的 Key 只在本机页面填写，不需要放进聊天。
不要编造功能、命令、个人经历或模型连接成功的结果。

界面内还有「先看怎么用」和「交给我的 AI」。前者在未连接时也能解释，后者能按任务生成交接说明并可选加入素材。AI 写好后，复制文字到结果框保存为新章节。

直接打开 index.html 可以填写与备份，但 API 连接要使用本地服务。两种打开方式的浏览器保存位置不同，移动前先备份。API 服务的账号、余额和开通模型由用户自己的服务决定；网页聊天会员不代表已经有 API 权限。
