开发计划与当前状态

v0.2：本地可操作工具

已实现三语界面与采访问题、通俗解释、AI 交接、六类场景、文字材料、固定问答与 API 追问、多本项目的本机浏览器保存、可编辑章节、事实检查请求、人工审阅状态、文字备份恢复、Markdown 与浏览器打印。Windows 启动器可准备官方 Node.js LTS。

API 适配按官方资料实现，测试使用模拟响应。未用真实使用者 Key 逐一验证每家服务的账号权限和连通性。浏览器语音输入依赖设备与浏览器，不等于音频文件转写。

下一步：真实使用验证

先请使用者完成恋人短篇或老人一章：能否理解开头说明，找到 Key / 自己的 AI 入口，保存并恢复，写出像本人的文字，最后做成可读样品。根据卡住的地方改界面，不先扩充模型数量。

后续功能

  • 上传音频文件的 ASR，转写校对和原音频位置关联。
  • 图片、扫描信件与 OCR；明确区分识别与事实确认。
  • 指定平台聊天格式适配，不把“JSON 能读”称作所有聊天都支持。
  • 老人长篇的章节材料管理、摘要与检索；多人的冲突版本保留。
  • 图文排版与打印打样、相册和 NAS 的可选衔接。

每项完成后再修改能力说明，不宣称已自动部署外部项目或完成真实打印验证。
