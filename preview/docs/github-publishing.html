GitHub 仓库与发布

仓库地址：SkyPiggy8/memory-for-human，公开可见，默认分支 main。下载 ZIP 后，Windows 用户可以双击 start.cmd。

仓库资料

  • 名称：memory-for-human
  • 简介：Local-first memoirs, guided by your own AI. 中文 / English / Español. Personal, noncommercial use.
  • Topics：memoir、oral-history、family-history、ai-writing、local-first、personal-archive
  • 许可：PolyForm Noncommercial 1.0.0，非商业使用；第三方内容保留自己的许可。

三语 README、图示和说明随仓库下载。preview/ 是文档预览，根目录 index.html 是可操作应用，两者分别维护。

更新前检查

  • 新能力在三语说明中一致，计划和已完成的部分写清楚。
  • 提交列表里没有 Key、本机配置、真实作品和私人材料。
  • 图片、链接和第三方出处完整，文档预览已更新。
  • 相关测试通过；模拟 API 响应没有写成真实账号实测。

按 AGENTS.md 检查后，提交并推送。.github/workflows/checks.yml 运行核心数据与本机 API 测试。GitHub 保存代码、说明、模板和虚构示例；使用者的回忆录留在其设备中。
