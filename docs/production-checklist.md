# 从稿件到纪念物：成品制作清单

这里把「制作清单」分成 BOM（需要准备的物品与文件）和步骤。先做一个低成本样品，再决定是否买硬件或批量印制。MFH 当前可导出文字、通过浏览器打印另存 PDF，不会自动完成图文排版、操作打印服务或同步相册；下面是人工制作流程。

## 所有成品的起点

- [ ] 讲述者已经审阅，疑点解决或保留明确标记。
- [ ] 明确读者与份数，家人版和公开版分开准备。
- [ ] 目录、姓名、日期、图片说明与封面已经校对。
- [ ] 有审定稿、原始材料和来源目录的独立备份。
- [ ] 照片、书信、采访与第三方素材的使用范围已经确认。

## A. 纸质回忆录

### 准备清单（BOM）

| 准备项 | 最少需要 | 选用说明 |
| --- | --- | --- |
| 审定文稿 | 一份 | 先在 Word、WPS 或其他熟悉的排版工具中整理 |
| 照片与说明 | 按章节挑选 | 保留原图，避免只用聊天软件压缩图 |
| 目录、序言、封面 | 各一份 | 署名与书名由本人确定 |
| 打印文件 | 内页 PDF；封面按店家要求 | 先确定尺寸、装订和印刷规格再导出 |
| 打样 | 一本或若干代表页 | 包含封面、文字页、照片页和双页接缝 |
| 印制服务 | 本地数码快印店、图文店或在线印制商 | 比较实际样品、沟通与报价，不预设指定商家 |

### 操作步骤

1. **找服务。** 在地图平台搜索「数码快印」「图文印刷」「照片书」，或在常用购物平台搜索「回忆录印刷」「少量书籍装订」。先询问是否接个人少量印制。
2. **确定规格。** 说明大约页数、成品尺寸、份数、黑白或彩色、纸张、封面、装订方式及交期。请店家发文件要求与样品照片。
3. **排版。** 按店家的页面尺寸、出血、内侧装订边距、单双页和封面规格整理。字号以实际读者为准，给老人看的版本先打印一页试读。
4. **处理照片。** 优先用原图，按最终版面检查清晰度。文字与人物脸部不要贴裁切线或跨装订缝；低分辨率原件宁可缩小使用。
5. **导出 PDF。** 检查字体嵌入、图片、页序和空白页。内页与封面是否分文件，按店家说明准备。
6. **核对封面。** 书脊厚度取决于纸张与页数，等店家给出尺寸后制作；不要提前猜一个固定厚度。
7. **先打样。** 看实体书，再检查错字、暗部、肤色、接缝、裁切、字号与翻阅舒适度。
8. **定稿下单。** 修改后确认最终文件、数量、价格与配送。交付给店家的只包含需要印制的稿件，不附原始聊天或录音。

### 可以复制的询价话术

> 我想少量印制一本家庭回忆录，预计约［页数］页，［份数］本。希望成品尺寸为［尺寸 / 请推荐］，内页［黑白 / 彩色 / 混合］，有约［数量］张照片。请提供纸张和装订建议、单本与多本报价、打样费用、制作周期，以及内页和封面的 PDF 文件要求。书脊、出血和内侧边距请按实际工艺告知。

本清单不承诺固定商家、价格或通用印刷参数；具体参数以承接印制的店家为准。

## B. 纸质照片书 / AI 辅助相册

**准备：** 精选原图、每张照片的时间与人物说明、简短章节文字、封面、排版工具或照片书服务、样品一本。

1. 先按事件选照片，再挑选每个事件的代表图；不必把所有照片都装进一本书。
2. AI 可以依据你提供的背景拟定标题、照片顺序和说明，事实由本人确认。
3. 修复旧照片时保留原图与修复版本，标明修复性质。AI 生成的历史场景配图必须写「AI 示意图」，不能冒充当年的真实照片。
4. 按照片书服务的规格排版，检查裁切、双页接缝和文字可读性。
5. 打样校对，完成后保存原图、审定说明与可再次制作的文件。

## C. 数字相册与硬件相框

### 路径 1：先用现有设备

| 准备项 | 是否必须 | 用途 |
| --- | --- | --- |
| 闲置平板、电脑或现有数字相框 | 是 | 展示照片与故事卡 |
| 照片文件与文字卡片 | 是 | 按事件命名，说明可直接排成图片 |
| 供电与摆放支架 | 视设备而定 | 根据设备说明使用 |
| 存储卡、U 盘或本地相册 | 视设备而定 | 按设备支持的导入方式选择 |

先试播 10 张照片和 3 张故事卡，检查横竖比例、字的大小、顺序与轮播时间，再整理整套内容。录音播放不是所有相框都有的能力，先查设备规格或改在平板上使用。

### 路径 2：自己组装（可选）

**准备：** 支持的软件与设备组合、树莓派或其他受支持电脑、屏幕、相匹配的电源、存储、连接线、支架或外壳，以及测试用照片。先根据软件当前文档选择设备，不预设通用兼容性。

可参考 [picframe 官方项目](https://github.com/helgeerbe/picframe)：面向树莓派照片展示，可通过 MQTT 等接口控制。它是独立项目，MFH 没有打包、集成或验证具体硬件组合。

步骤是：用受支持设备启动项目 → 测试照片目录 → 调整显示方向与轮播 → 导入故事卡 → 再安装外壳与摆放。先验证显示效果再购买整套配件。

## D. 家庭档案与 NAS

**基础准备：** 本机材料文件夹、一份独立外置存储副本、文件清单、版本日期与保管人记录。没有 NAS 也能完成。

1. 原始材料和成品分别存放，但用编号相互关联。
2. 建议做到 3 份副本、2 类存储介质、1 份异地副本。照片工具 [Immich 官方仓库](https://github.com/immich-app/immich)也提醒用户采用这类备份策略。
3. 独立副本定期更新，保留一份不持续连接电脑的副本；同步删除的文件不等于可恢复备份。
4. 有 NAS 时，可在受支持的环境中另行部署照片或文档管理工具。原始资料和数据库都需要按工具说明备份。
5. 每次大幅修改和最终成书后保留一个日期版本。定期抽查能否打开照片、播放录音和恢复项目。
6. 给家人留一份说明：文件存在哪里、谁有读取权限、怎样恢复。不要只依赖某个人的 AI 账号。

NAS 是保存位置与服务平台，不会自动保证永久保存。相关项目见[延伸工具](ecosystem.md)。
