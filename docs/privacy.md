# 私人材料与本人审阅

回忆录涉及的人，决定自己的材料怎样被采集、交给 AI 和分享。录音、照片、聊天和第三人的经历，请分别确认用途；家人版与公开版可以不同。

## 当前工具怎样处理资料

项目文字保存在当前设备、当前浏览器地址的 IndexedDB 中。服务只监听本机 `127.0.0.1`，不提供公开账户或远程托管。页面没有统计、广告或自动上传全部项目的功能。

固定提问、填写、文字整理、手动编辑和导出无需调用模型。点击 API 按钮时，所选答案与材料会经本机服务发送给配置的 AI；审阅也会发送当前章节。导入文字默认不勾选，答案也可以逐份取消使用。在线 AI 的保留规则按该服务执行，本项目不能替你删除其记录。

「交给我的 AI」默认不附私人材料；勾选后把选中素材放进说明。交给在线工具就会发送其中内容，交接包不包含 API Key。

Key 默认只保存在本机服务本次运行的内存中，不进入浏览器项目、备份、文稿或日志。关闭服务后需要重填。选择用 `user-config.local.json` 启动配置的人，需要自己保护这个本机明文文件；它被 Git 忽略且不会通过本机静态服务提供。

## 保存与搬迁

浏览器保存不是唯一备份。隐私浏览、清除数据、更换浏览器、从文件模式改成本地地址、换端口或换设备，都可能看不到原来的保存位置。先下载完整文字备份，再到新的位置导入。

备份包含本项目文字和草稿，不包含原始音频和照片。恢复会新增一本，不覆盖原来的内容。原始材料与成品还要有独立副本。

## 审阅

AI 草稿不是事实确认。检查姓名、时间、经过、原话来源、他人隐私与本人口吻。引用编号可以辅助回到材料；无法保证所有模型始终按要求生成。修改审阅过的章节后，工具会重新标为草稿。

讲述者可以不回答、删减、不成书或只在家庭内分享。战友、同事等场景只记录可分享资料，不导入保密内容。

私人材料与作品放在仓库外或 `private/` 中，不进入公共 GitHub。`.gitignore` 只是减少误提交，不是加密或完整防护；发布前仍需检查文件列表。
