## 贡献与反馈

最有帮助的反馈是具体的一步：哪个问题不好回答，在哪里找不到按钮，恢复备份后有什么不对，哪种故事的提纲不合适。说明你想写什么、做到了哪一步，以及希望怎么改。

开发前阅读 [AGENTS.md](../AGENTS.md)、根目录中文 README 和 [AI 交接](ai-handoff.md)。界面仍支持三语；以后默认只维护中文 README，英文、西班牙语保留现有版本。核心或服务改动运行 `npm test`，操作流程变化再做真实浏览器检查。API 测试使用模拟服务；没有授权与真实凭据，不调用使用者的服务。

请用虚构或已授权并匿名化的示例。真实聊天、家庭照片、录音、地址、账号和 Key 不提交到公共仓库。

新功能先对照[开发计划](development.md#roadmap)。还没实现的能力保留在计划中，引用第三方项目注明出处，独立工具不能写成已集成。技术比较说明资料范围，不把他人文档的遗漏当成功能缺失。

贡献需能按本项目的 [Apache-2.0 / MIT 双许可](../LICENSE) 分发，并保留必要的[第三方声明](THIRD_PARTY_NOTICES.md)。

## 当前进度与后续工作

### v0.3 已经可以用的部分

本机界面支持中文、英文、西班牙语，六类采访各有问题和模板。现在可以填写、导入文字、保存多本回忆录、逐章编辑、手动交给自己的 AI，或接入 API 采访和写作。章节有本人审阅状态，可以备份恢复、导出 Markdown 和浏览器打印。Windows 启动器可以准备官方 Node.js LTS。

每种语言的问题库从 60 个扩为 156 个，一生回忆从 18 个扩为 48 个。AI 追问规则改为先补具体场景，再转到未聊的话题，一次只问一个问题。是否问得合适，还需要真实采访验证。

API 传输测试使用模拟响应，没有逐一验证使用者真实账号。语音输入取决于浏览器，不是上传录音的自动转写。

照片现在可以直接上传到本机工作区，填写内容和意义，交给自己的 AI 建议章节与段落位置。本人确认后进入图文预览、浏览器打印和包含原图的 ZIP。完整 JSON 备份带上照片和位置，恢复仍新增一本。模型读取的是人写的说明，没有识图和 OCR。

写作规则也从“整理材料”扩为“持续采访后改写”：根据已讲的经过补足叙述、调整衔接和措辞，缺事实就继续问。当前章可让 AI 扩写和润色，改写前的稿子留在章内；位置确认会随着文字修改失效，出稿前重新核对。

### 先验证一章

找愿意试用的家庭，分别完成一段恋人故事和一章老人的经历。看他们能否打开工具、理解问题、找到自己的 AI、保存恢复，以及把稿子改成像本人说的话。记录卡住的步骤，再改界面和问法。这些使用验证尚未完成。

### 后续开发

| 工作 | 要解决的问题 | 做完后怎样检查 |
| --- | --- | --- |
| 音频文件转写 | 录音能转成可校对文字，仍能回到原音 | 人名、方言、多发言人和时间位置 |
| 图片识别与 OCR | 在现有照片保存和人工说明之上，增加可核对的识别文字 | 误识别可修改，原件不丢 |
| 指定聊天格式 | 正确识别某个平台的导出内容 | 时间、发言人、附件与异常格式 |
| 长篇事件和章节索引 | 管理先后、来源与不同说法 | 摘要或检索不抹去不确定项 |
| 多人审阅 | 各人的补充和修改有归属 | 不替多人决定哪个版本真实 |
| 专业印刷排版与存档 | 在已有图文稿上补封面、目录、印刷规格及长期存档 | 实际打样、备份恢复与设备兼容 |

完成一项，再把它写进能力说明。相关设计依据见[技术说明](technical.md#architecture)和[参考项目](technical.md#related-work)。

## GitHub 更新与发布

仓库地址：[SkyPiggy8/memory-for-human](https://github.com/SkyPiggy8/memory-for-human)，公开可见，默认分支 `main`。下载 ZIP 后，Windows 用户可以双击 `start.cmd`。

### 仓库资料

- 名称：`memory-for-human`
- 简介：Local-first memoirs, guided by your own AI. 中文 / English / Español. Apache-2.0 OR MIT.
- Topics：`memoir`、`oral-history`、`family-history`、`ai-writing`、`local-first`、`personal-archive`
- 许可：[Apache-2.0 / MIT 双许可](../LICENSE)，任选一种，允许商业使用；第三方内容保留自己的许可。

中文 README 是日常维护入口，现有译文集中在 `docs/translations/`。`preview/` 只保留界面会打开的六份页面，根目录 `index.html` 是可操作应用。

### 更新前检查

- [ ] 新能力在三语说明中一致，计划和已完成的部分写清楚。
- [ ] 提交列表里没有 Key、本机配置、真实作品和私人材料。
- [ ] 图片、链接和第三方出处完整，文档预览已更新。
- [ ] 相关测试通过；模拟 API 响应没有写成真实账号实测。

按 [AGENTS.md](../AGENTS.md) 检查后，提交并推送。`.github/workflows/checks.yml` 运行核心数据与本机 API 测试。GitHub 保存代码、说明、模板和虚构示例；使用者的回忆录留在其设备中。
