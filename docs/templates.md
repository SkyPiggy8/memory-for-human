## 恋人的故事

可以只写一次旅行，也可以写你们相识到现在的经历。双方各自的说法分别记录，不必把这段关系写成一种固定结局。

### 开始前记几项

- 暂定书名、讲述者、帮忙记录的人：
- 时间范围（可以只写大概）：
- 写给谁，谁可以阅读：
- 本人讲述 / 多人分别讲述 / 代记录并注明：
- 篇幅参考：3,000–15,000 字；材料少就短一点。
- 哪些材料允许交给外部 AI：
- 不想聊、不想写或不想公开的内容：

先问：有哪件事情改变了你们的相处？

原始回答：

先问：有哪件小事，你想让对方知道你一直记得？

原始回答：

### 写一章前

- 保留本人原话；没有准确记录的对白只写大意。
- 不同人的回忆注明讲述者，不确定的时间不补成精确日期。

## 原件登记

这张表放在自己的材料目录里，不在公共仓库填写。每份原件用一个编号，转写、照片说明和章节都能引用它。编号不要复用。

页面自动分配的 `A…`、`M…` 与这里手工写的 `SRC…`、`PHOTO…` 各自保留。把原件编号写进导入材料的说明，方便以后回查。

### 项目

- 名称、讲述者、记录人：
- 录音、外部 AI 与作品分享的同意范围：
- 原件位置、独立备份位置：

| 编号 | 类型 | 原件位置 | 谁提供的 | 采集日期 | 事件时间（可不确定） | 允许用途 | 校对状态 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| SRC-001 | 录音 | raw/待填写.m4a | | | | | 未转写 / 已转写 / 已校对 |
| PHOTO-001 | 照片 | raw/待填写.jpg | | | | | 待本人核对 |

### 每份材料另记

- 怎样取得原件：
- 转写、OCR 或校正稿在哪里：
- 原音时间位置或扫描页码：
- 哪些听不清、记不清或有不同说法：
- 已用于哪些事件和章节：
- 哪些不能交给外部 AI 或放进公开稿：
- 后来改过什么，谁确认的：

### 每张照片的内容和意义

页面上传照片后会分配 `P…` 编号。可以照着下面填写；已经在来源登记表里编过号，就在说明里写清对应关系。

```text
页面照片编号：P1（以页面实际编号为准）
独立原件编号、位置：
照片里的人、地点、约略时间：
画面中正在发生什么：
哪些内容已确认，哪些记不清：
这张照片为什么值得留下：
它让我想到的一件事：
允许 AI 使用文字说明：是 / 否
允许放进哪一版书：家庭版 / 公开版 / 暂不采用
建议章节、段落与配文：由 AI 提议或自己选择
本人是否核对了位置和配文：
```

内容和意义写好后，可以请 AI 安排位置，也可以先拿照片问一个小问题。比如“照片里这间铺子，第一次进去时在做什么？”回答留在采访记录里，整理章节时再用。不能从照片推断出的事情不要替本人填。

## 虚构采访与工作稿示例

以下人物、经历和材料编号全部虚构，用来说明怎样从采访写成工作稿。它不是应用运行记录，也不能用来证明模型效果。

### 原始采访 · SRC-DEMO-001

采集者：第一天去做学徒，有什么记得很清楚的事？

讲述者：应该是六十年代末，哪一年不记得了。修理铺离家不远，我走过去的。师傅先让我扫地、整理工具。那把扳手比我想的沉，第一次拿的时候差点没握住。我中午带了饭，坐在门口吃。

采集者：师傅当时说了什么？

讲述者：具体的话想不起来了。他让我先看，不急着动手。

### 先记下已知的事

| 内容 | 记录 |
| --- | --- |
| 事件 | 第一天在修理铺做学徒 |
| 时间 | 约六十年代末，具体年份未确认 |
| 人物、地点 | 讲述者与师傅，家附近的修理铺；姓名地址未提供 |
| 细节 | 步行、扫地、整理工具、扳手沉、中午吃自带的饭 |
| 来源 | SRC-DEMO-001 |
| 下次补问 | 最先学会修什么？ |

### 工作稿：那把很沉的扳手

我去修理铺当学徒，大约是在六十年代末。具体哪一年，现在已经记不清了。铺子离家不远，我第一天是走过去的。【来源：SRC-DEMO-001】

师傅先让我扫地、整理工具。我记得一把扳手，比想象中沉，第一次拿起来时差点没握住。中午，我坐在门口，吃自己带来的饭。【来源：SRC-DEMO-001】

师傅当时说的原话，我想不起来。大意是让我先看，不急着动手。【来源：SRC-DEMO-001】

### 读回去，再继续

这段可以读给本人听，改成他习惯的说法。天气、师傅姓名和当时的情绪没有材料，就不补写。下一次问“你最先学会修什么”，也可以到这里停下。

读者版可以去掉编辑用的来源标记，但“大约”“记不清”“大意”仍保留。[制作清单](guide.md#production)说明之后怎样排版、打印和保存。
