# 现在做到哪里，接下来做什么

## v0.2 已经可以用的部分

本机界面支持中文、英文、西班牙语，六类采访各有问题和模板。现在可以填写、导入文字、保存多本回忆录、逐章编辑、手动交给自己的 AI，或接入 API 采访和写作。章节有本人审阅状态，可以备份恢复、导出 Markdown 和浏览器打印。Windows 启动器可以准备官方 Node.js LTS。

每种语言的问题库从 60 个扩为 156 个，一生回忆从 18 个扩为 48 个。AI 追问规则改为先补具体场景，再转到未聊的话题，一次只问一个问题。是否问得合适，还需要真实采访验证。

API 传输测试使用模拟响应，没有逐一验证使用者真实账号。语音输入取决于浏览器，不是上传录音的自动转写。

## 先验证一章

找愿意试用的家庭，分别完成一段恋人故事和一章老人的经历。看他们能否打开工具、理解问题、找到自己的 AI、保存恢复，以及把稿子改成像本人说的话。记录卡住的步骤，再改界面和问法。这些使用验证尚未完成。

## 后续开发

| 工作 | 要解决的问题 | 做完后怎样检查 |
| --- | --- | --- |
| 音频文件转写 | 录音能转成可校对文字，仍能回到原音 | 人名、方言、多发言人和时间位置 |
| 图片与 OCR | 保存原图，识别文本单独核对 | 误识别可修改，原件不丢 |
| 指定聊天格式 | 正确识别某个平台的导出内容 | 时间、发言人、附件与异常格式 |
| 长篇事件和章节索引 | 管理先后、来源与不同说法 | 摘要或检索不抹去不确定项 |
| 多人审阅 | 各人的补充和修改有归属 | 不替多人决定哪个版本真实 |
| 图文排版与存档 | 稿件能制成实物、以后还能找回 | 实际打样、备份恢复与设备兼容 |

完成一项，再把它写进能力说明。相关设计依据见[技术说明](architecture.md)和[参考项目](related-work.md)。
